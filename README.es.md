Estrellas a partir de reseñas de hoteles, de TF-IDF a ModernBERT con regresión ordinal CORN. El README indica R² = 0,75 y 70 % de accuracy. Abre `TP4_Hotel_Rating_Prediction.ipynb` (también `tp3*.ipynb`, `tp4.ipynb`, `tp5.ipynb`, `tp4.py`).

```bash
pip install -r requirements.txt
```
